# 匿名试点指标与反馈

本文件是试点记录模板，不代表已经开展真实试点。指标只保存按周/试点轮次汇总的数据，不得记录姓名、学号、手机号、OpenID、预约理由原文、照片、token、IP 或可反推个人身份的小样本明细。

## 指标口径

| 指标 | 计算方式 | 价值 |
|---|---|---|
| 预约提交成功率 | 成功创建预约数 ÷ 有效提交尝试数 | 识别接口、上传和校验障碍 |
| 自动分房成功率 | 获得候选房间的预约数 ÷ 有效预约请求数 | 验证空间规则覆盖度 |
| 冲突阻止数 | 被容量/独占/物理房间冲突正确拒绝的请求数 | 衡量替代人工排房的价值 |
| 审核耗时中位数 | 从提交到首次审核的分钟数中位数 | 衡量管理员效率 |
| 签到完成率 | 已签到预约数 ÷ 应签到且已开始预约数 | 衡量现场使用闭环 |
| 清扫闭环率 | 已提交且复核完成数 ÷ 已结束需清扫预约数 | 衡量空间维护闭环 |
| 有效使用率 | 实际签到分钟数 ÷ 可预约空间开放分钟数 | 辅助调整空间和规则 |
| 错误恢复率 | 用户点击重试后成功的错误次数 ÷ 可重试错误次数 | 验证弱网可恢复性 |

## 反馈摘要

每轮最多记录三类非个人化结论：

1. 最影响完成任务的步骤：待填写。
2. 最有价值的自动化能力：待填写。
3. 下一候选版需要验证的假设：待填写。

原始访谈、日志和截图如确需保留，应进入学校批准的受控存储，不提交到公开 Git 仓库。
