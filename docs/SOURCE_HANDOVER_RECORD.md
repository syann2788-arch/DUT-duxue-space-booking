## 2. 交付范围与责任分工草案

以下是待双方确认的安排，不能当作学校已接受的合同或签字。已授权执行的开发方工作是整理源码材料、验证、提交并推送；服务器部署、体验版及正式上线协助是否纳入本次工作，由双方在下表确认。

| 工作 | 建议负责角色 | 当前安排 / 学校确认 |
|---|---|---|
| 固定源码、教程、校验值、已知限制、检查证据 | 开发交付方 | 本轮整理并提交；学校接收待确认 |
| 学校服务器、网络、域名、证书及续期 | 学校运维/网络负责人 | 资源与具体责任人待学校确认 |
| 后端部署、数据库和媒体、备份恢复、日常告警 | 学校运维；开发方按约定协助 | 是否需开发方部署协助待确认 |
| AppID 主体、成员、AppSecret、模板及平台审核 | 小程序管理员 | 由学校管理员控制；开发方协助范围待确认 |
| 前端构建与体验版上传 | 已绑定开发者；小程序管理员配合 | 实际 API 地址及双方责任待确认 |
| 账号身份核验、预约规则、隐私与素材权利 | 学校业务/身份/隐私责任人 | 第 4 节逐项决定 |
| 交付缺陷修复、后续需求、技术支持 | 开发交付方与学校共同约定 | 第 5 节登记，不默认永久维护 |
