# 15 分钟可复现演示脚本

本脚本只使用虚构数据。不要导入真实辅导员表、学号、手机号或照片。

1. 创建虚拟环境并安装 `backend/requirements-dev.txt`。
2. 复制 `.env.example`，设置随机的演示管理员账号和密码后运行 `seed.py`。
3. 启动 FastAPI，确认 `/api/health/ready` 返回数据库 `ok`。
4. 在 Swagger 注册两个虚构学生账号，手机号使用专门的测试号段/占位值且不得与真人对应。
5. 导入仓库根目录到微信开发者工具，完成学生登录、场景选择、连续时段和玉兰卡测试图上传。
6. 用虚构管理员审核预约；学生查看状态推进、取消边界和使用结束后的清扫待办。
7. 上传专门生成的无个人信息清扫图，管理员执行通过与退回各一次。
8. 展示违约/限制、辅导员专属 A106、Excel 导出和系统配置。
9. 运行后端与小程序测试，展示 `dist/wechat/BUILD_INFO.json`。

真实截图、2–3 分钟录屏和试点指标必须来自经过授权的候选版本，不得用合成界面冒充验收证据。
