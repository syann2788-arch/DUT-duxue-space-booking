# 第六批本地收尾报告

日期：2026-08-13  
范围：仅记录不需要学校、微信公众平台或 GitHub 管理权限即可完成的工作。

## 已实现

- 管理端 Excel 可按开始日期、结束日期、场景和预约状态筛选，日期反转会在客户端和后端同时拦截。
- 管理端可鉴权生成并预览房间签到二维码，仍保留复制 JSON 的兼容入口；二维码响应禁止共享缓存。
- 预约状态推进和个人历史查询新增复合索引，迁移版本升级为 `20260813_02`。
- 管理端筛选、二维码鉴权/格式、索引存在性均有自动化回归测试。
- 筛选与签到码序列化抽到 `miniprogram/utils/admin-tools.js`，避免继续把纯逻辑堆入管理页面。
- 补充直接依赖与许可证盘点，明确项目许可证必须由权利人决定。
- 运行公开漏洞数据库扫描；升级 FastAPI、文件上传解析器和测试框架，并以 PyJWT 替换存在无修复公告的 python-jose。升级后后端锁定依赖扫描未发现已知漏洞；参考 `frontend/` 的 npm 锁文件审计也未报告漏洞。

## 本地演示数据
