## 操作与部署前提

- 用户：我的 → 修改密码；忘记密码 → 使用管理员重置凭证。
- 管理员：用户详情填写核验原因与管理员密码 → 签发凭证 → 通过受控渠道仅交给已核验本人。
- 服务端先备份，再在backend目录执行 `../.venv/bin/alembic upgrade head`，之后启动API与worker。本次未升级原有shuyuan.db。
- 首个生产管理员：迁移完成后运行 `../.venv/bin/python create_admin.py`，交互输入密码。
- CLI辅导员导入：设置COUNSELOR_CSV_PATH和COUNSELOR_CREDENTIALS_OUTPUT后运行import_counselors.py；凭据文件不得加入Git，发放后按学校保管策略处置。
